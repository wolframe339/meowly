# Meowly 🐾

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)
[![Tauri](https://img.shields.io/badge/Tauri-v2-orange)](https://tauri.app)

> **A beautifully designed, lightweight cross-platform client for any OpenAI-compatible API.**

Meowly connects to OpenAI, OpenRouter, Ollama, or local models — all in one chill, native-feeling app for macOS and Windows.

*(UI SCREENSHOT)*

## ✨ Features
- 🚀 **Blazing fast:** Built on Tauri, no heavy Electron bloat.
- 🎨 **Beautiful UI:** Distraction-free, modern design with dark/light modes.
- 🔌 **Provider agnostic:** Works with any OpenAI-compatible endpoint.
- 🔒 **Local & Secure:** API keys are stored in your OS Keychain. No telemetry.

## 📦 Installation
Download the latest release for your OS:
- [macOS (Apple Silicon / Intel)](https://github.com/ТВОЙ_НИК/meowly/releases)
- [Windows (x64)](https://github.com/ТВОЙ_НИК/meowly/releases)

## 🛠️ Development
Want to build it yourself?
```bash
git clone https://github.com/ТВОЙ_НИК/meowly.git
cd meowly
npm install
npm run tauri dev
```
